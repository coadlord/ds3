TITLE: QUICK SORT, MERGE SORT AND HEAP SORT
AIM: Sort a list using three sorting algorithms.

ALGORITHM:
Quick Sort:
1. Choose the last element as pivot.
2. Separate smaller/equal values and larger values.
3. Recursively sort both parts and combine them.

Merge Sort:
4. Divide the list into two halves until each part has one item.
5. Merge the halves in sorted order.
6. Continue until the full list is sorted.

Heap Sort:
7. Convert the list to a min heap.
8. Repeatedly remove the smallest item to build a sorted list.
9. Display the result of each method.

PROGRAM:
import heapq

def quick_sort(a):
    if len(a) <= 1:
        return a
    pivot = a[-1]
    left = [x for x in a[:-1] if x <= pivot]
    right = [x for x in a[:-1] if x > pivot]
    return quick_sort(left) + [pivot] + quick_sort(right)

def merge_sort(a):
    if len(a) <= 1:
        return a
    mid = len(a) // 2
    left = merge_sort(a[:mid])
    right = merge_sort(a[mid:])
    result = []
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
    result.extend(left[i:])
    result.extend(right[j:])
    return result

def heap_sort(a):
    heap = a[:]
    heapq.heapify(heap)
    result = []
    while heap:
        result.append(heapq.heappop(heap))
    return result

values = [40, 10, 50, 20, 30]
print("Quick Sort:", *quick_sort(values))
print("Merge Sort:", *merge_sort(values))
print("Heap Sort:", *heap_sort(values))

OUTPUT:
Quick Sort: 10 20 30 40 50
Merge Sort: 10 20 30 40 50
Heap Sort: 10 20 30 40 50

RESULT: All three sorting methods sorted the list successfully.
