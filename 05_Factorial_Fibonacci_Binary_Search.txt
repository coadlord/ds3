TITLE: FACTORIAL, FIBONACCI AND BINARY SEARCH
AIM: Calculate factorial, print Fibonacci numbers and search a sorted list.

ALGORITHM:
1. Define recursive factorial: return 1 when n is 0 or 1; otherwise return n times factorial(n-1).
2. Calculate 5! with a loop and with recursion.
3. Define Fibonacci recursively: return n for n <= 1; otherwise return fib(n-1)+fib(n-2).
4. Print the first five Fibonacci numbers.
5. Store sorted values 10, 20, 30, 40 and 50; set key to 30.
6. Set low to the first index and high to the last index.
7. Find the middle index and compare its value with the key.
8. If equal, record its one-based position; if smaller, search right; otherwise search left.
9. Display all results.

PROGRAM:
def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)

def fib(n):
    if n <= 1:
        return n
    return fib(n - 1) + fib(n - 2)

fact = 1
for i in range(1, 6):
    fact *= i
print("Factorial using loop =", fact)
print("Factorial using recursion =", factorial(5))
print("Fibonacci:", *(fib(i) for i in range(5)))

a = [10, 20, 30, 40, 50]
key = 30
low, high = 0, len(a) - 1
position = -1
while low <= high:
    mid = (low + high) // 2
    if a[mid] == key:
        position = mid + 1
        break
    elif a[mid] < key:
        low = mid + 1
    else:
        high = mid - 1
if position != -1:
    print("30 found at position", position)
else:
    print("30 not found")

OUTPUT:
Factorial using loop = 120
Factorial using recursion = 120
Fibonacci: 0 1 1 2 3
30 found at position 3

RESULT: Factorial, Fibonacci and binary search were completed.
