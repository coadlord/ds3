TITLE: FIRST FIT AND BEST FIT MEMORY ALLOCATION
AIM: Allocate memory blocks using First Fit and Best Fit.

ALGORITHM:
First Fit:
1. Store block sizes 100, 500, 200 and 300.
2. Store process sizes 212, 100 and 300.
3. For each process, scan blocks from the beginning.
4. Select the first block with enough remaining space.
5. Allocate the process and reduce that block's remaining size.
6. If no block is large enough, display not allocated.

Best Fit:
7. Start again with the original block sizes.
8. For each process, find the smallest remaining block large enough for it.
9. Allocate the process and reduce that block's remaining size.
10. Display allocation results for both methods.

PROGRAM:
blocks = [100, 500, 200, 300]
processes = [212, 100, 300]

first_fit = blocks[:]
print("First Fit:")
for process in processes:
    chosen = -1
    for i in range(len(first_fit)):
        if first_fit[i] >= process:
            chosen = i
            break
    if chosen == -1:
        print(process, "not allocated")
    else:
        print(process, "allocated to B" + str(chosen + 1))
        first_fit[chosen] -= process

best_fit = blocks[:]
print("Best Fit:")
for process in processes:
    chosen = -1
    for i in range(len(best_fit)):
        if best_fit[i] >= process:
            if chosen == -1 or best_fit[i] < best_fit[chosen]:
                chosen = i
    if chosen == -1:
        print(process, "not allocated")
    else:
        print(process, "allocated to B" + str(chosen + 1))
        best_fit[chosen] -= process

OUTPUT:
First Fit:
212 allocated to B2
100 allocated to B1
300 allocated to B4
Best Fit:
212 allocated to B4
100 allocated to B1
300 allocated to B2

RESULT: First Fit and Best Fit memory allocation were performed successfully.
