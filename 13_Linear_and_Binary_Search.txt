TITLE: LINEAR SEARCH AND BINARY SEARCH
AIM: Search for a key using linear and binary search.

ALGORITHM:
1. Store the sorted list 10, 20, 30, 40 and 50.
2. Set the key to 30.
3. For linear search, compare the key with each item from the beginning.
4. If a match is found, record the one-based position.
5. For binary search, set low to the first index and high to the last index.
6. Find the middle index and compare its value with the key.
7. If equal, record the position and stop.
8. If the middle value is smaller, search the right half; otherwise search the left half.
9. Display the positions or not-found messages.

PROGRAM:
values = [10, 20, 30, 40, 50]
key = 30
linear_position = -1

for i in range(len(values)):
    if values[i] == key:
        linear_position = i + 1
        break

low = 0
high = len(values) - 1
binary_position = -1
while low <= high:
    mid = (low + high) // 2
    if values[mid] == key:
        binary_position = mid + 1
        break
    elif values[mid] < key:
        low = mid + 1
    else:
        high = mid - 1

if linear_position != -1:
    print("Linear Search Position =", linear_position)
else:
    print("Linear Search: Not Found")
if binary_position != -1:
    print("Binary Search Position =", binary_position)
else:
    print("Binary Search: Not Found")

OUTPUT:
Linear Search Position = 3
Binary Search Position = 3

RESULT: Linear and binary search were performed successfully.
