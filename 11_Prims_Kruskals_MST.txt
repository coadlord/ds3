TITLE: PRIM'S AND KRUSKAL'S MINIMUM SPANNING TREE
AIM: Calculate the MST cost using Prim's and Kruskal's algorithms.

ALGORITHM:
Prim's:
1. Store the graph as a weighted adjacency matrix.
2. Start with vertex 0 marked visited.
3. Find the smallest edge from a visited vertex to an unvisited vertex.
4. Add its weight to the cost and mark the new vertex visited.
5. Repeat until all vertices are visited.

Kruskal's:
6. Store all edges as (weight, start vertex, end vertex).
7. Sort edges in ascending order of weight.
8. Initially, every vertex belongs to a separate set.
9. For each edge, find the sets of its endpoints.
10. If the endpoints are in different sets, select the edge and join the sets.
11. Stop after selecting n-1 edges.
12. Display both MST costs.

PROGRAM:
graph = [
    [0, 1, 3, 0],
    [1, 0, 2, 4],
    [3, 2, 0, 5],
    [0, 4, 5, 0]
]
n = len(graph)
visited = [False] * n
visited[0] = True
prim_cost = 0

for _ in range(n - 1):
    smallest = float("inf")
    next_vertex = -1
    for u in range(n):
        if visited[u]:
            for v in range(n):
                if not visited[v] and graph[u][v] != 0:
                    if graph[u][v] < smallest:
                        smallest = graph[u][v]
                        next_vertex = v
    if next_vertex != -1:
        prim_cost += smallest
        visited[next_vertex] = True

edges = [(1, 0, 1), (3, 0, 2), (2, 1, 2), (4, 1, 3), (5, 2, 3)]
edges.sort()
parent = list(range(n))

def find(x):
    while parent[x] != x:
        x = parent[x]
    return x

kruskal_cost = 0
selected = 0
for weight, u, v in edges:
    root_u = find(u)
    root_v = find(v)
    if root_u != root_v:
        parent[root_u] = root_v
        kruskal_cost += weight
        selected += 1
    if selected == n - 1:
        break

print("Prim's MST Cost =", prim_cost)
print("Kruskal's MST Cost =", kruskal_cost)

OUTPUT:
Prim's MST Cost = 7
Kruskal's MST Cost = 7

RESULT: Both algorithms calculated the minimum spanning tree cost.
